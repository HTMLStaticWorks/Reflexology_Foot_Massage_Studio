# Sole Harmony — Reflexology & Foot Massage Studio

A calming, traditional, premium reflexology website built with vanilla HTML, CSS, and JavaScript. Designed with an **organic luxury** aesthetic inspired by Asian wellness traditions.

## Features

- **11 fully-designed pages** — Home, Home 2, About, Services, Blog, Blog Single, Contact, Login, Register, 404, Coming Soon
- **Dark / Light Mode** — System preference detection + localStorage persistence
- **RTL Support** — Full right-to-left layout with `dir="rtl"` toggle
- **Responsive Design** — 5 breakpoints: 1440px, 1024px (hamburger), 768px, 360px
- **Hero Animations** — Parallax, staggered fade-in, typing effect
- **Interactive Pressure Point Map** — Click/hover to explore reflexology zones
- **Testimonials Carousel** — Auto-advancing with dot navigation
- **Tabbed Services** — Filter treatments by category
- **Form Validation** — Client-side validation on all forms
- **Scroll Reveal** — Intersection Observer animations
- **Wave Dividers** — SVG organic section separators
- **Floating Shapes** — CSS animated decorative elements

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Structure | HTML5 (semantic) |
| Styling | Vanilla CSS (CSS variables, Grid, Flexbox) |
| Interactivity | Vanilla JavaScript (ES6+) |
| Icons | Lucide Icons (CDN) |
| Fonts | Google Fonts (Cormorant Garamond + Nunito Sans) |
| Images | Unsplash CDN |
